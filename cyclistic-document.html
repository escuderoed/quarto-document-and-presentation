How do annual members and casual riders use Cyclistic bikes differently?

Author

Eduardo Escudero

Report guide

This report follows the official Cyclistic roadmap: Ask, Prepare, Process, Analyze, Share, and Act. The goal is to identify how annual members and casual riders use Cyclistic bikes differently and translate those findings into business recommendations.

1 Ask

1.1 Business task

Cyclistic’s marketing team wants to understand how annual members and casual riders use the bike-share system differently. The specific business task for this case study is to answer the following question:

How do annual members and casual riders use Cyclistic bikes differently?

The answer should support future marketing decisions designed to convert casual riders into annual members.

1.2 Stakeholders

  • Lily Moreno, Director of Marketing
  • Cyclistic marketing analytics team
  • Cyclistic executive team

1.3 Why this matters

Understanding behavioral differences between the two rider groups can help Cyclistic design more targeted marketing strategies, improve messaging, and focus conversion efforts on the usage patterns that distinguish casual riders from members.

2 Prepare

2.1 Data source

The analysis uses the previous 12 months of Cyclistic historical trip data stored as monthly CSV files named with the format YYYYMM-divvy-tripdata.csv. Each row represents one bike trip.

Data source notes
  • The data is public and suitable for analyzing system usage patterns.
  • Personally identifiable information is not available, so the analysis focuses on trip behavior rather than customer identity.
  • This limitation prevents linking trips to rider demographics, home locations, or repeated purchases across individuals.

2.2 Data organization

The files are stored locally in a folder and loaded into R. The dataset is organized at the trip level, where each record includes ride metadata such as bike type, timestamps, station information, coordinates, and user type.

2.4 Data credibility and limitations

The dataset is credible for analyzing trip behavior, but it still has important limitations:

  • It is appropriate for studying differences between casual riders and annual members because it includes timestamps, bike type, coordinates, and rider category.
  • It does not include personally identifiable information, so it cannot explain who the riders are beyond their user type.
  • Some variables contain missing values, especially for electric bike trips.
  • A small number of rides have invalid durations or incomplete trip-end coordinates and must be handled before analysis.

3 Process

3.1 Tools used

This project uses R because it allows fast loading of multiple CSV files, flexible data cleaning, reproducible transformations, and direct generation of tables and visualizations inside a single Quarto report.

3.2 Data cleaning and feature engineering

The following steps were applied:

  1. Append the 12 monthly files into one dataframe.
  2. Create year, month, and month_name from the file name.
  3. Create start_date and end_date from the ride timestamps.
  4. Create an English weekday variable.
  5. Create ride duration variables in minutes and seconds.
  6. Review missing values, date ranges, and implausible durations.
  7. Filter out invalid trips and extreme outliers.
Show code 
weekday_levels <- c("Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday")

divvy_all <- divvy_all %>%
  mutate(
    started_at = ymd_hms(started_at),
    ended_at = ymd_hms(ended_at),
    start_date = as.Date(started_at),
    end_date = as.Date(ended_at),
    weekday_num = wday(start_date, week_start = 1),
    weekday = factor(weekday_levels[weekday_num], levels = weekday_levels, ordered = TRUE),
    duration_min = as.numeric(difftime(ended_at, started_at, units = "mins")),
    duration_sec = as.numeric(difftime(ended_at, started_at, units = "secs"))
  )

Main data quality issues
  • A small number of trips have negative or zero duration and should not be kept for analysis.
  • Some trips are missing end coordinates, which limits any analysis involving ride destinations.
  • Electric bike trips contain most of the missing station information, so that pattern appears to be operational rather than random.
  • Very long ride durations exist in the upper tail and can distort averages if they are not filtered.

3.4 Filtering decisions

To improve data quality, the dataset was filtered by removing trips with invalid duration, trips with missing end coordinates, and unusually long rides above the 99.5th percentile of duration.

Show code 
divvy_filter_base <- divvy_all %>%
  filter(
    duration_sec > 0,
    !is.na(end_lat),
    !is.na(end_lng)
  )

cutoff_995 <- quantile(divvy_filter_base$duration_sec, 0.995, na.rm = TRUE)

divvy_filter <- divvy_filter_base %>%
  filter(duration_sec <= cutoff_995)

filter_summary <- tibble(
  original_rows = nrow(divvy_all),
  valid_rows = nrow(divvy_filter_base),
  final_filtered_rows = nrow(divvy_filter),
  removed_invalid_rows = nrow(divvy_all) - nrow(divvy_filter_base),
  removed_outlier_rows = nrow(divvy_filter_base) - nrow(divvy_filter),
  total_removed_rows = nrow(divvy_all) - nrow(divvy_filter),
  p99_5_duration_sec = as.numeric(cutoff_995),
  p99_5_duration_min = round(as.numeric(cutoff_995) / 60, 2)
)

5.2 Key findings

  • Casual riders typically take longer trips than annual members.
  • Casual usage is more concentrated on Saturday and Sunday, which suggests more recreational riding behavior.
  • Member usage is more concentrated on weekdays, which is more consistent with commuting or routine transportation.
  • Seasonal and hourly patterns can help identify the moments when casual riders are most likely to be receptive to membership conversion strategies.

6 Act

6.1 Final conclusion

Annual members and casual riders use Cyclistic bikes differently in both trip duration and timing of use. Casual riders tend to take longer rides and are more active on weekends, while annual members ride more consistently during the workweek and may rely on the system more for practical transportation.

6.2 Top three recommendations

  1. Target weekend casual riders with conversion offers. Weekend behavior suggests that casual riders are highly engaged during leisure periods, making post-ride promotions and app-based membership messages especially relevant on Saturdays and Sundays.
  2. Promote membership value around frequent-use scenarios. Since members appear to use the bikes more regularly during weekdays, Cyclistic should highlight cost savings, convenience, and routine usage benefits in campaigns aimed at frequent casual riders.
  3. Use digital media around the moments of highest intent. Hourly and weekday patterns can be used to schedule ads, push notifications, and email campaigns when casual riders are most active and more likely to consider a membership upgrade.

6.3 Additional data that would improve the analysis

  • Rider-level history showing whether casual users repeatedly return to the system.
  • Pricing response data for single rides, day passes, and membership promotions.
  • Weather data, holidays, and event calendars to explain seasonal or peak-day effects.
  • More detailed station-level or route-level behavior if future business questions shift from user type differences to geographic strategy.

# Ask

## Business task

Cyclistic's marketing team wants to understand how **annual members** and **casual riders** use the bike-share system differently. The specific business task for this case study is to answer the following question:

> **How do annual members and casual riders use Cyclistic bikes differently?**

The answer should support future marketing decisions designed to convert casual riders into annual members.

## Stakeholders

-   **Lily Moreno**, Director of Marketing
-   **Cyclistic marketing analytics team**
-   **Cyclistic executive team**

## Why this matters

Understanding behavioral differences between the two rider groups can help Cyclistic design more targeted marketing strategies, improve messaging, and focus conversion efforts on the usage patterns that distinguish casual riders from members.

# Prepare

## Data source

The analysis uses the previous 12 months of Cyclistic historical trip data stored as monthly CSV files named with the format `YYYYMM-divvy-tripdata.csv`. Each row represents one bike trip.

::: callout-note
## Data source notes

-   The data is public and suitable for analyzing system usage patterns.
-   Personally identifiable information is not available, so the analysis focuses on trip behavior rather than customer identity.
-   This limitation prevents linking trips to rider demographics, home locations, or repeated purchases across individuals.
:::

## Data organization

The files are stored locally in a folder and loaded into R. The dataset is organized at the **trip level**, where each record includes ride metadata such as bike type, timestamps, station information, coordinates, and user type.

## Data credibility and limitations

The dataset is credible for analyzing **trip behavior**, but it still has important limitations:

-   It is appropriate for studying differences between casual riders and annual members because it includes timestamps, bike type, coordinates, and rider category.
-   It does **not** include personally identifiable information, so it cannot explain *who* the riders are beyond their user type.
-   Some variables contain missing values, especially for electric bike trips.
-   A small number of rides have invalid durations or incomplete trip-end coordinates and must be handled before analysis.

# Process

## Tools used

This project uses **R** because it allows fast loading of multiple CSV files, flexible data cleaning, reproducible transformations, and direct generation of tables and visualizations inside a single Quarto report.

## Data cleaning and feature engineering

The following steps were applied:

1.  Append the 12 monthly files into one dataframe.
2.  Create `year`, `month`, and `month_name` from the file name.
3.  Create `start_date` and `end_date` from the ride timestamps.
4.  Create an English `weekday` variable.
5.  Create ride duration variables in minutes and seconds.
6.  Review missing values, date ranges, and implausible durations.
7.  Filter out invalid trips and extreme outliers.

```{r}
#| label: feature-engineering

weekday_levels <- c("Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday")

divvy_all <- divvy_all %>%
  mutate(
    started_at = ymd_hms(started_at),
    ended_at = ymd_hms(ended_at),
    start_date = as.Date(started_at),
    end_date = as.Date(ended_at),
    weekday_num = wday(start_date, week_start = 1),
    weekday = factor(weekday_levels[weekday_num], levels = weekday_levels, ordered = TRUE),
    duration_min = as.numeric(difftime(ended_at, started_at, units = "mins")),
    duration_sec = as.numeric(difftime(ended_at, started_at, units = "secs"))
  )
```

## Main data quality issues

-   A small number of trips have negative or zero duration and should not be kept for analysis.
-   Some trips are missing end coordinates, which limits any analysis involving ride destinations.
-   Electric bike trips contain most of the missing station information, so that pattern appears to be operational rather than random.
-   Very long ride durations exist in the upper tail and can distort averages if they are not filtered.
:::

## Filtering decisions

To improve data quality, the dataset was filtered by removing trips with invalid duration, trips with missing end coordinates, and unusually long rides above the **99.5th percentile** of duration.

```{r}
#| label: apply-filters

divvy_filter_base <- divvy_all %>%
  filter(
    duration_sec > 0,
    !is.na(end_lat),
    !is.na(end_lng)
  )

cutoff_995 <- quantile(divvy_filter_base$duration_sec, 0.995, na.rm = TRUE)

divvy_filter <- divvy_filter_base %>%
  filter(duration_sec <= cutoff_995)

filter_summary <- tibble(
  original_rows = nrow(divvy_all),
  valid_rows = nrow(divvy_filter_base),
  final_filtered_rows = nrow(divvy_filter),
  removed_invalid_rows = nrow(divvy_all) - nrow(divvy_filter_base),
  removed_outlier_rows = nrow(divvy_filter_base) - nrow(divvy_filter),
  total_removed_rows = nrow(divvy_all) - nrow(divvy_filter),
  p99_5_duration_sec = as.numeric(cutoff_995),
  p99_5_duration_min = round(as.numeric(cutoff_995) / 60, 2)
)

kable(filter_summary, caption = "Filtering summary")
```

# Act

## Final conclusion

Annual members and casual riders use Cyclistic bikes differently in both **trip duration** and **timing of use**. Casual riders tend to take longer rides and are more active on weekends, while annual members ride more consistently during the workweek and may rely on the system more for practical transportation.

## Top three recommendations

1.  **Target weekend casual riders with conversion offers.** Weekend behavior suggests that casual riders are highly engaged during leisure periods, making post-ride promotions and app-based membership messages especially relevant on Saturdays and Sundays.
2.  **Promote membership value around frequent-use scenarios.** Since members appear to use the bikes more regularly during weekdays, Cyclistic should highlight cost savings, convenience, and routine usage benefits in campaigns aimed at frequent casual riders.
3.  **Use digital media around the moments of highest intent.** Hourly and weekday patterns can be used to schedule ads, push notifications, and email campaigns when casual riders are most active and more likely to consider a membership upgrade.

## Additional data that would improve the analysis

-   Rider-level history showing whether casual users repeatedly return to the system.
-   Pricing response data for single rides, day passes, and membership promotions.
-   Weather data, holidays, and event calendars to explain seasonal or peak-day effects.
-   More detailed station-level or route-level behavior if future business questions shift from user type differences to geographic strategy.
